# OctoAcme Project Management Docs

A quick-start index to OctoAcme’s project management guidance. OctoAcme uses a customer-first, iterative approach with clear ownership, measurable outcomes, and regular communication. Projects move through initiation (validate the need and align stakeholders), planning (prioritize and estimate work, define acceptance criteria and milestones), execution (deliver and track work, manage risks, and test quality), release (deploy, verify, and communicate), and close/retrospective (capture learnings and improvements). Project Managers coordinate delivery, risks, schedules, and communications; Product Managers own outcomes and prioritization; delivery teams build and validate the work with stakeholders.
